# Обновление ThreadSmith — пошаговая инструкция

## Что нового
- Админка (начисление кредитов, выдача тарифов, статистика)
- Главное меню + команда /menu для возврата
- Автопостинг: бот сам пишет посты и ставит в очередь
- Онбординг голоса стал бесплатным (было 10 кредитов)

## ШАГ 1. Узнай свой Telegram ID

В Telegram напиши боту **@userinfobot** любое сообщение.
Он ответит числом вида `123456789` — это твой ID. Запиши.

Открой github.com → репозиторий `threadsmith`.

**Файлы на ЗАМЕНУ (перезаписать существующие):**

| `app/bot/main.py` | папка `app/bot` |

| `app/bot/handlers/menu.py` | папка `app/bot/handlers` |

**Как заливать:**
1. В GitHub зайди в нужную папку (например, кликни `app` → `core`)
2. Кнопка **Add file** → **Upload files**
3. Перетащи файл
4. Внизу **Commit changes**
5. Повтори для каждой папки

При замене существующих файлов GitHub спросит подтверждение — соглашайся.

## ШАГ 3. Прогони миграцию в Supabase

1. Открой Supabase → твой проект → **SQL Editor**
2. Вставь и нажми **Run**:

```sql
create table if not exists autocontent_settings (
  user_id bigint primary key references users(id),
  active bool default false,
  posts_per_day int default 1,
  created_at timestamptz default now()
);
```

3. Должно написать **Success**

---

## ШАГ 4. Добавь свой ID в .env на сервере

Открой консоль Timeweb (сервер threadsmith → вкладка Консоль).

Вставь команду, заменив `123456789` на свой ID из Шага 1:

```
echo 'ADMIN_IDS=123456789' >> /root/threadsmith/.env
```

Нажми **Enter**.

Проверь, что записалось:
```
grep ADMIN /root/threadsmith/.env
```

## ШАГ 5. Обнови сервер

В той же консоли по одной команде (каждая + Enter, дождись окончания):

```
cd /root/threadsmith
```

```
git pull
```

```
docker compose down
```

```
docker compose up -d --build
```

Сборка займёт 2-3 минуты. Дождись строк `Started`.

## ШАГ 6. Проверь

В Telegram боту:

1. `/menu` — должно открыться главное меню
2. `/admin` — должна открыться админка (только у тебя)
3. `/stats` — статистика

Админ-команды:
- `/give 123456789 100` — начислить 100 кредитов юзеру
- `/plan 123456789 pro` — выдать тариф Про
- `/user 123456789` — инфо о юзере

Автопостинг: Автопилот → Автопостинг (нужны голос + ниша + Threads).
